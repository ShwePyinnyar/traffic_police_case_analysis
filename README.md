## Traffic Police Data Analysis

This project analyzes traffic stop cases using a dataset from Kaggle.  
The objective is to practice data cleaning, filtering, grouping, and aggregation using Python (pandas).

---

## Questions Answered

### Q1. Data Cleaning
- Removed columns that contain only missing (null) values.

### Q2. Filtering & Value Counts
- For speeding violations, were men or women stopped more often?

### Q3. GroupBy Analysis
- Does driver gender affect who gets searched during a traffic stop?

### Q4. Mapping & Data Type Casting
- What is the mean stop duration after mapping categorical values and converting data types?

### Q5. GroupBy & Describe
- Compared age distributions for each type of traffic violation.
